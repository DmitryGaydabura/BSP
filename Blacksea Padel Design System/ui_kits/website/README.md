# Blacksea Padel — Website UI Kit

## Overview
High-fidelity recreation of the Blacksea Padel club website. Navy + gold palette, Cinzel display type, Raleway body.

## Screens
1. **Homepage** — Hero, courts overview, booking CTA, stats
2. **Courts** — Court listing with availability
3. **Booking** — Court booking flow
4. **Membership** — Plans and pricing

## Components
- `Header.jsx` — Navigation bar with logo, links, CTA
- `Hero.jsx` — Full-bleed hero with headline + CTA
- `CourtsSection.jsx` — Court cards grid
- `BookingCard.jsx` — Booking form card
- `Footer.jsx` — Footer with links and contact

## Design Width
1280px desktop, responsive down to 375px mobile.

## Usage
Open `index.html` — it's a click-through prototype of the homepage → courts → booking flow.
